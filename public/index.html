📝 格式说明（点击展开） 
四种上传模式：

[A] PDF（约 30 秒 ~ 3 分钟）
  PDF → pdf2x.cn 转 Markdown → Claude 生成卡片
  需要 pdf2x.cn 的 API Key（右上角 🔑 设置）
  免费 100 次调用，获取地址：https://pdf2x.cn/api/apikey/page

[B] Markdown / TXT 单文件（约 1-3 分钟）
  直接把读书笔记扔进来，Claude 自动生成卡片

[C] ZIP 素材包（约 1-3 分钟）
  book.zip
  ├─ SKILL.md             # 或任意 .md / .txt
  └─ references/
     ├─ chapter01.md
     └─ chapter02.md

[D] ZIP 成品直传（秒级）
  book.zip
  ├─ book.json            # { title, author, subtitle, description, tapeColor, accentColor }
  ├─ cards.json           # 卡片数组
  └─ cover.png            # 可选

cards.json 格式:
[
  {
    "id": "c1",
    "type": "term",        // term|people|counter|quote|action|tech|wild
    "title": "心流 Flow",
    "fields": {
      "首创者": "Mihaly Csikszentmihalyi",
      "诞生时间": "1975",
      "原始定义": "..."
    },
    "source": "《Beyond Boredom and Anxiety》",
    "tags": ["心理学"]
  }
]

七种卡片类型与配色:
📘 term     术语卡     蓝
👤 people   人名卡     紫
💥 counter  反常识卡   红
✨ quote    金句卡     橙
🎯 action   行动卡     绿
🔧 tech     技巧卡     青
🃏 wild     任意卡     灰

🔑 设置 pdf2x.cn API Key

仅上传 PDF 时需要。Key 保存在你本地浏览器（localStorage），不会上传到任何服务器。

  1. 去 pdf2x.cn/api/apikey/page 用手机号获取 Key（免费 100 次调用）
  2. 复制生成的 Key（形如 sk-xxxxx…）
  3. 粘贴到下面的输入框，点击保存
