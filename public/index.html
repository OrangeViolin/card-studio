新增一本书

支持 PDF / Markdown / TXT / ZIP，以及整个文件夹（递归读 .md/.txt）。拖拽到下方，或点击选择。

贴一个网页链接，服务器会抓正文 → Claude 生成卡片。

粘贴一段文字（文章、笔记、聊天记录、任何长文）— Claude 自动生成卡片。

从一个远端 URL 拉 cards.json 或 book.zip（含 book.json + cards.json），直接导入书架。

📝 格式说明（点击展开） 
四个上传 tab：

[文件] 文件 / 文件夹 / ZIP（约 1-3 分钟，PDF 视解析模式另算）
  · PDF          → 服务器解析成 Markdown → LLM 生成卡片
  · Markdown / TXT 单文件 → 直接喂给 LLM
  · 整个文件夹    → 递归收集 .md/.txt，合并后喂给 LLM
  · ZIP 素材包    → 里面一堆 .md/.txt
  · ZIP 成品直传  → 秒级落盘（见下方 book.json + cards.json 结构）

[网页链接] 粘一个 URL（约 1-3 分钟）
  服务器抓网页正文 → LLM 生成卡片

[粘贴文本] 长文/笔记/聊天记录（约 1-3 分钟）
  贴啥都行，服务器当素材处理

[订阅] 远端 cards.json 或 book.zip（秒级）
  贴一个 URL，一次性拉下来进书架

------

ZIP 成品直传结构：
book.zip
├─ book.json    # { title, author, subtitle, description, tapeColor, accentColor }
├─ cards.json   # 卡片数组
└─ cover.png    # 可选

cards.json 格式：
[
  {
    "id": "c1",
    "type": "term",         // term|people|counter|quote|action|tech|wild
    "title": "心流 Flow",
    "fields": {
      "首创者": "Mihaly Csikszentmihalyi",
      "诞生时间": "1975",
      "原始定义": "..."
    },
    "source": "《Beyond Boredom and Anxiety》",
    "tags": ["心理学"]
  }
]

七种卡片类型与配色：
📘 term     术语卡     蓝
👤 people   人名卡     紫
💥 counter  反常识卡   红
✨ quote    金句卡     橙
🎯 action   行动卡     绿
🔧 tech     技巧卡     青
🃏 wild     任意卡     灰

部署模式（由后端环境变量控制，前端不用关心）：
· LLM：cli（本地 Claude）/ mock（离线假数据）/ http（内网 OpenAI 兼容端点）
· PDF 解析：local（内置 pdf-parse）/ v1（自建服务）/ pdf2x（pdf2x.cn）

🔑 设置 pdf2x.cn API Key

仅上传 PDF 时需要。Key 保存在你本地浏览器（localStorage），不会上传到任何服务器。

  1. 去 pdf2x.cn/api/apikey/page 用手机号获取 Key（免费 100 次调用）
  2. 复制生成的 Key（形如 sk-xxxxx…）
  3. 粘贴到下面的输入框，点击保存
